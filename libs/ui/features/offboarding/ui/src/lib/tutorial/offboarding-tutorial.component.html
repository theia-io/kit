Create new offboarding experience in 2 steps.

1st step - Company:

  • Upload your company logo,
  • Add title (optional).
  • Add message / wishes from a company for departing colleague (optional).
  • Add collaborative kudoboard for messages from colleagues (optional).

2st step - Person who leaves:

  • Enter email (personal or work email) of departing colleague
  • Ask for a company review on different platforms (optional).
  • Start collecting kudos from colleagues and send for farewell message from departing colleague.

Optional (*optional) fields are filtered out when you create and later view experience.
